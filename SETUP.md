# Português — Cartões: запуск на iPhone

Как устроено: `index.html` — страница с карточками, словарь лежит в ней же (WORDS, VERBS, FRASES, PARES). `quiz.js` — режим «Hoje» (ежедневное повторение). Прогресс хранится в браузере на устройстве, на сервер ничего не уходит.

## 1. Опубликовать (один раз)

1. **GitHub Desktop** → File → Add Local Repository → выбрать папку `Português (cartões)` → он предложит «create a repository» → нажать.
   - Name: `portugues-cartoes` (латиницей, без ç и õ — это будет частью адреса).
   - Create Repository.
2. Нажать **Publish repository**. Снять галочку «Keep this code private»: бесплатная публикация (GitHub Pages) работает только для публичных репозиториев. В репо только слова, личных данных нет.
3. На github.com открыть репозиторий → **Settings → Pages** → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты там же появится адрес вида `https://<аккаунт>.github.io/portugues-cartoes/`. Его открываем на iPhone.

## 2. На iPhone (один раз)

1. Открыть адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
2. **Дальше заходить только через этот значок.** У значка своё хранилище, отдельное от вкладки Safari: если открыть сайт во вкладке, прогресса там не будет.
3. Голос получше (бесплатно): Настройки → Универсальный доступ → Устный контент → Голоса → Португальский → **Joana (улучшенный)** → скачать. Страница подхватит его сама.
4. Если звука нет — проверить громкость и бесшумный режим. Первую озвучку iPhone запускает только после нажатия, поэтому сначала нажмите «Hoje».

## 3. Ежедневное напоминание

Напоминания → новое: «Português · Hoje», дата сегодня, время на выбор, **Повтор: ежедневно**. Ссылку в напоминание не вставлять: она откроется в Safari, а прогресс лежит в значке на экране «Домой». Увидела напоминание — открываешь значок.

## 4. Каждый день

Значок → **Hoje** → «Show answer» → «Got it» / «Forgot». В день: всё, что подошло по сроку (до 15), плюс новые (по умолчанию 5; меняется на экране «Done for today»).
Интервалы: Got it → через 1, 3, 7, 14, 30 дней. Forgot → ещё раз в конце сессии и снова завтра.

**Раз в месяц:** экран «Done for today» → **Export progress**, сохранить файл в iCloud Drive. При смене телефона — Import progress.

## 5. Новые слова и фразы

Добавляешь в чате, как раньше → файл `index.html` обновляется → GitHub Desktop: **Commit to main → Push origin** → через минуту обновится сайт. Новые карточки сами попадут в квиз.

Для того чата: массивы называются `WORDS`, `VERBS`, `FRASES`, `PARES`, поля прежние. Если переименовать массив или завести новый, квиз его не увидит: тогда нужно дописать его в `collect()` в `quiz.js`. Прогресс привязан к тексту карточки: если исправить написание, карточка начнётся заново.
