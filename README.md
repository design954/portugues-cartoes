# Português — Cartões

Карточки европейского португальского (pt-PT) с транскрипцией кириллицей, переводом и озвучкой.

Сайт: https://design954.github.io/portugues-cartoes/

## Уроки и разделы

Меню ☰ сужает показ до одного урока; по умолчанию открыто всё (All lessons).

- **Lição 1–2** — Substantivos (существительные с артиклем и родом), Pares (пары слов)
- **Lição 3** — Verbos (глаголы с предлогами), Frases (словосочетания), Posso / podes, Orações (предложения)
- **Lição 4** — фразы

## Режимы

- **Hoje** — ежедневное повторение с интервалами (1, 3, 7, 14, 30 дней)
- **▶ Practice** — 10 карточек выбранного раздела: сначала PT → RU, потом RU → PT
- **▶ Study** (во вкладке Verbos) — глагол, затем все фразы с ним; отметки «Got it / Forgot» и повтор только незнакомых

**Мотивация:** цель дня — 20 ответов в любом режиме (меняется), серия дней подряд с выполненной целью, полоска недели, салют при выполнении цели и 11 медалей. Экран «Progress & medals» — по нажатию на полоску цели или из меню ☰.

Прогресс хранится в браузере на устройстве. Сохранить или перенести его можно кнопками Export / Import progress в конце сессии «Hoje».

## Файлы
